## Create new categories and add existing categories
As shown in the figure, use the button inside the red rectangle to create a brand-new category to serve as the parent or child of the current category; use the button inside the green circle to add an existing category to serve as the parent or child of the current category.

![](/assets/images/iCategory/category/new-add-category.png)

## Remove and delete categories
Slide your finger left on a category, which reveals the actions you can do on that account. See the figure below.
You can google the [swipe gesture](https://www.google.com/search?q=ios+gesture+swipe+list+item) if you are not familiar with this operation.
1. "Remove" means severing the parent-child relationship between the selected category and the current category; it does not actually delete the selected category itself (the category remains in the app).
2. "Delete" means removing the selected category entirely; it will no longer exist in the app.
