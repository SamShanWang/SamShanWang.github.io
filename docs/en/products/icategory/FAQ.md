## Typical workflow for using this app
1. First, build a category structure. This structure is used to classify and organize items systematically. 
    1. Each category can have multiple subcategories and multiple parent categories and multiple items. 
    2. Unlike common category structures (such as file systems)—where each category is limited to a single parent—categories, in this app (with the exception of the *Top Category*) can have more than one parent category. 
    3. See: [Help - Category](/en/icategory/category)
2. Next, add items and assign each item to one or more categories. 
    1. Unlike file system structures (where an item belongs to only one folder), each item here can belong to multiple categories. 
    2. These items can be anything: personal collections, household objects or tools, commercial supplies, or even virtual items like movies, music, and e-books. 
    3. See: [Help - Item](/en/icategory/item)
3. Finally, create inventory lists and export them as CSV files for your use. 
    1. Based on the unique category structure and items you have created, the app automatically generates organized inventory lists tailored to your needs.
    2. See: [Help - Inventory List](/en/icategory/inventorylist)
