## Introduction
The budgeting function employs the same concepts as GnuCash and is compatible with it. 
Please refer to the relevant official GnuCash documentation: 
1. [Zero-Based Budgeting](https://wiki.gnucash.org/wiki/Zero-Based_Budgeting)
2. [Chapter 14. Budgets](https://www.gnucash.org/docs/v5/C/gnucash-guide/chapter_budgets.html)

## How to new, delete, and modify a budget?
Slide your finger left on a budget, which reveals the actions you can do on that budget. See the figure below.
You can google the [swipe gesture](https://www.google.com/search?q=ios+gesture+swipe+list+item) if you are not familiar with this operation.

![](/assets/images/MyLedger/budget/budget-CUD.png)

## How to set the planned value of the budget and view the actual value?
As shown in the figure below, you can set the budget plan value for each account and view the corresponding actual value in real time.

![](/assets/images/MyLedger/budget/budget-detail.png)

## How to copy budget plan values from other periods?
As shown in the figure below, you can use the 'Copy From' menu in the upper right corner to copy planned values from other budget periods to the currently open period.

![](/assets/images/MyLedger/budget/budget-copyfrom.png)
